# D&D Dice Roller

**Author:** Bethany Feddes

A simple web application for rolling dice for D&D or other tabletop RPGs. Users can select a die type (d4, d6, d8, d10, d12, d20, or d100) and roll it, with the result displayed on screen. The dice roll automatically when the page loads, and pressing Enter rolls again at any time.

## Features

- Select from standard TTRPG die types (d4–d100)
- Roll results displayed in a read-only field
- Automatically rolls on page load
- Press Enter to roll again, regardless of what's focused on the page

## How to Run

This is a static website (HTML, CSS, and JavaScript only) — no build step or server required.

1. Clone or download this repository.
2. Open `index.html` directly in any modern web browser (double-click the file, or right-click → Open With → your browser).

Alternatively, the live hosted version can be viewed here: [Web Dice Roller](https://salmon-mud-0aaca3410.6.azurestaticapps.net/)

## Files

- `index.html` — page structure and content
- `style.css` — styling and layout
- `script.js` — dice-rolling logic and event handling
